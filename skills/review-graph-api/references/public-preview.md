# Public Preview (Beta) Review Criteria

Review criteria specific to beta (public preview) API documentation.

---

## Beta Disclaimer

**Required** in ALL beta reference topics, immediately after the namespace declaration:

```markdown
[!INCLUDE [beta-disclaimer](../../includes/beta-disclaimer.md)]
```

- Missing beta disclaimer in beta content = **BLOCKER**
- Placement: after namespace declaration, before description

## Doc Stub Validation

Autogenerated doc stubs often **overgenerate API topics**. Validate:

- Only operations confirmed in API.md and Documentation Plan are documented
- Overgenerated CRUD stubs for unsupported operations are ignored
- Methods tables include only supported methods
- Presence of a doc stub does NOT mean the operation is supported

## Polymorphic Entity Types

When the Documentation Plan flags a polymorphic collection (⚠️ caveat block with "polymorphic collection"):

| Area | Rule |
|---|---|
| **File naming** | Use base type name for all shared operation files (abstract or concrete base) |
| **Doc stubs** | Skip derived type operation stubs and their permissions files |
| **Base type resource** | Includes Methods table; Properties/Relationships show only base type's own + inherited |
| **Derived type resources** | NO Methods table — only a polymorphic note under `## Methods` directing to base type |
| **POST/PATCH requests** | Include `@odata.type` guidance when targeting polymorphic collections |

### Derived Type Resource Rules

- Description must reference and link to base type
- Properties include derived-type-specific + inherited
- `## Methods` section contains only a note (no table):
  > "For the methods available for this resource type, see the base type [baseName](../resources/basename.md)."

## National Cloud Include

- Beta API files may have an autogenerated national cloud support statement before `## Permissions`
- Do NOT add this statement when authoring new files — it's added automatically
- Delete when copying from beta to v1.0

## Code Snippets in Beta

- Include only HTTP request examples
- No SDK snippet includes, tab declarations, or tab boundary markers
- SDK snippets are generated automatically by a separate pipeline

## Quality Checklist (Beta-Specific)

In addition to the base quality checklist:

- [ ] Beta disclaimer present in all beta files
- [ ] Only supported operations documented (per API.md / Documentation Plan)
- [ ] Polymorphic types handled correctly (if applicable)
- [ ] No v1.0 content accidentally included in beta-only files
- [ ] Doc stubs for unsupported operations were not used
- [ ] Missing doc stubs flagged as blockers (not skipped silently)
